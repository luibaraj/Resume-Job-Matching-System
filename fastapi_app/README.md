# Resume-to-Job Matching API

FastAPI service that exposes the resume-to-job matching pipeline as a REST API.

## Prerequisites

1. **Python 3.11** and `pip`
2. **Ollama** running locally with the `llama3.2:3b-instruct-q4_K_M` model pulled
3. **Environment variables** set in `.env` (see `.env.example`)
4. **Pipeline data** generated by running the pipeline scripts:

```bash
# From the project root
python scripts/pipeline/scrape_jobs.py
python scripts/pipeline/preprocess_jobs.py
python scripts/pipeline/embed_jobs.py
```

## Installation

1. Install dependencies:

```bash
cd fastapi_app
pip install -r requirements-fastapi.txt
```

2. Ensure the parent project dependencies are installed (from the root directory):

```bash
pip install -r requirements.txt
```

## Running the API

### Development

```bash
./scripts/start_api.sh
```

Or directly:

```bash
uvicorn app.main:app --host 0.0.0.0 --port 8000 --reload
```

### Docker

```bash
docker-compose up
```

## API Endpoints

### `GET /api/v1/health`

Health check endpoint that verifies connectivity to Ollama, the SQLite database, and ChromaDB.

### `POST /api/v1/match`

Match a resume against job listings.

**Request body:**
```json
{
  "resume_text": "Full resume text here...",
  "top_k": 100,
  "use_filters": true,
  "include_explanations": true
}
```

**Response:**
```json
{
  "matches": [
    {
      "id": 123,
      "title": "Data Scientist",
      "location": "San Francisco, CA",
      "company_name": "Example Corp",
      "board_token": "spacex",
      "source_url": "https://example.com/job/123",
      "min_years_experience": 2,
      "distance": 0.123,
      "rerank_score": 0.456,
      "explanation": "The candidate's experience in..."
    }
  ],
  "total_candidates": 100,
  "total_reranked": 10,
  "filters_applied": { ... }
}
```

## Architecture

The API orchestrates the same pipeline as the CLI:

1. **Embedding**: Voyage AI (`voyage-3.5-lite`) to embed the resume.
2. **Retrieval**: ChromaDB HNSW dense search (top‑K candidates).
3. **Reranking**: Cohere `rerank-english-v3.0` (top‑N results).
4. **Generation**: Ollama `llama3.2:3b-instruct-q4_K_M` for fit explanations.

All services are defined in `app/services/` and reuse the existing `src/` modules.

## Configuration

Settings are loaded from environment variables (see `app/config.py`). The most important are:

- `VOYAGE_API_KEY`
- `COHERE_API_KEY`
- `DB_PATH` (default: `../data/jobs.db`)
- `CHROMA_DIR` (default: `../data/chroma_db`)

## Development

- The API is built with FastAPI and uses Pydantic for validation.
- Dependencies are injected via FastAPI's `Depends`.
- The service layer is fully unit‑testable.
